# **Automatic Servo Motor Control Using Arduino**

### **AIM** 

A simple servo motor control system using an **Arduino Uno**. The servo motor is connected to the Arduino and programmed to rotate between different angles automatically. This demonstrates how an Arduino can control the position and movement of a servo motor.

### **Required Materials**

* Arduino Uno  
* Servo motor  
* Jumper wires  
* USB cable  
* Computer / laptop

### **Procedure**

1. Select the required components.  
2. Connect the servo motor to the Arduino Uno.  
3. Connect the servo **signal wire** to digital pin **7**.  
4. Connect the servo **VCC** wire to the Arduino **5V** pin.  
5. Connect the servo **GND** wire to the Arduino **GND** pin.  
6. Connect the Arduino Uno to the computer using a USB cable.  
7. Upload the servo control program to the Arduino.  
8. The servo rotates to **0°**, then **180°**, and returns to **0°** with a short delay.  
9. Observe the automatic movement of the servo motor.

### **Notes**

* Connect the servo wires correctly.  
* Ensure the power and ground connections are secure.  
* Do not force the servo motor beyond its mechanical limits.  
* Make sure the Arduino program is uploaded correctly.  
* The servo motor can be used for applications such as automatic doors, robotic arms, and positioning systems.
